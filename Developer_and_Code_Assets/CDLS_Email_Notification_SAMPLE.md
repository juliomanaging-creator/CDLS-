## REPORT METRICS EXPLAINED

### Integrity Score Calculation
```
Integrity = (GPS_Score × 0.3) + (Energy_Score × 0.4) + (Financial_Score × 0.3)

Where:
  GPS_Score = 1 - (GPS_Variance / 100)
  Energy_Score = 1 - (Energy_Variance / 100)
  Financial_Score = 1 - (Financial_Variance / 100)

Example:
  GPS Variance: 2.3%
  Energy Variance: 2.7%
  Financial Variance: 2.1%
  
  GPS_Score = 1 - 0.023 = 0.977
  Energy_Score = 1 - 0.027 = 0.973
  Financial_Score = 1 - 0.021 = 0.979
  
  Integrity = (0.977 × 0.3) + (0.973 × 0.4) + (0.979 × 0.3)
            = 0.2931 + 0.3892 + 0.2937
            = 0.976 = 97.6%
```

### Status Determination
```
IF Integrity ≥ 95% AND all variances < 5%:
    Status = VERIFIED (green)
ELSE IF Integrity ≥ 85%:
    Status = REVIEW (orange)
ELSE:
    Status = EXCEPTION (red - immediate action)
```
