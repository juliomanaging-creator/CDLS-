# Clinical Protocol: Patient Data Handling
## HIPAA Compliance Standards
- **Encryption**: All PHI (Protected Health Information) must be encrypted at rest.
- **Access Control**: Role-Based Access Control (RBAC) is mandatory for EMR entry.

## Emergency Triage Flow
1. **Initial Assessment**: Check vital signs and neurological response.
2. **Data Logging**: Record time of entry and primary symptoms in local secure node.
